更新时间：2026-05-20

> 当前目标：先卖/验证一个固定范围、固定交付物、低持续依赖的轻服务，而不是继续堆 SaaS 功能。

## 一句话

我帮你审一份招聘 JD / 对外文案里的性别刻板印象和包容性表达风险，24-48 小时内给你一份可转发的修改报告。

## 适合谁

- HR / 招聘小团队：招聘 JD、岗位宣传、雇主品牌文案。
- 内容运营 / 市场：官网介绍、公众号、小红书、活动文案。
- 教育培训 / 招生：课程介绍、招生活动、社群招募。
- NGO / DEI：活动招募、倡议文案、志愿者文案。

## 交付物

### 免费样例审阅（前 10 个真实样本）

- 输入：1 段旧 JD / 对外文案，建议 300-1000 字，需脱敏。
- 输出：1 页 Markdown 审阅报告样例。
- 换取反馈：是否有用、哪里误报、是否会采用改写、是否愿意为完整版付费。

### 偏见表达审阅包（验证价 ¥99-299/次）

- 输入：1-3 段文本，总计建议 3000 字以内。
- 周期：24-48 小时。
- 输出：
  - 总体风险摘要。
  - 逐条风险标注。
  - 每条风险的原因说明。
  - 2-3 版替代表达。
  - 可直接复制的改写版本。
  - Markdown/PDF 报告。
  - 可选 10-15 分钟说明。

## 边界

- 不是法律/合规结论。
- 不给个人贴标签。
- 不承诺持续顾问服务。
- 不处理未脱敏的高度敏感材料。
- 每次只审约定范围内的文本；新增文本另算一次。
