# 今日触达行动卡：拿到第一份真实/脱敏样本

更新时间：2026-05-20

## 今天唯一目标

不要继续解释产品、不要继续打磨功能。今天只做一件事：**拿到 1 份真实/脱敏招聘 JD、招聘宣传、课程介绍或公开文案**，用于生成第一份真实样例审阅报告。

成功标准：有人发来一段 300-1000 字左右的真实/脱敏文本。

## 15 分钟执行法

### 第 1 步：选 3 个人

优先从低心理负担对象开始：

1. 最近发过招聘信息、帮公司招人、或转过 JD 的朋友。
2. 做 HR、猎头、招聘协调、创业团队运营的人。
3. 写课程介绍、公众号、小红书、官网文案、活动文案的人。

不要先找“最完美客户”。先找愿意随手转一段旧文本的人。

### 第 2 步：直接复制这条发出去

```text
我在验证一个小服务：免费帮前几份招聘 JD / 招聘宣传 / 公开文案做一页“包容性表达审阅报告”，主要看有没有容易引发性别刻板印象或表达不够中性的句子，并给可直接复制的改写版本。

你手头有没有一段旧 JD、招聘宣传、课程介绍或公开文案？可以脱敏后发我，300-1000 字最好。

脱敏建议：删掉公司内部信息、人名、手机号、邮箱、客户名。这个阶段我只想验证报告有没有用，不会公开原文，也不做法律/合规结论。
```

### 第 3 步：对方说“可以”后，复制这条

```text
太好了。你直接贴一段文本给我就行。

最好保留岗位/场景和大致表达，不然我不好判断；但请删掉公司内部信息、人名、手机号、邮箱、客户名。

我会回你一页报告：
1. 总体风险摘要
2. 逐条标出可能有争议的表达
3. 为什么可能有风险
4. 2-3 条替代表达
5. 一版可直接复制的改写文本

做完后只想请你反馈三件事：有没有用、哪里误报、你会不会采用其中的改写。
```

### 第 4 步：收到文本后，转给 codex

把对方给的文本通过内部邮件转给 codex，并补充这 5 个字段：

```text
样本类型：招聘 JD / 招聘宣传 / 课程介绍 / 营销文案 / 其他
使用场景：准备发布 / 已发布旧文案 / 内部草稿 / 只是测试
是否已脱敏：是 / 否
对方最关心：怕冒犯 / 想更专业 / 想给老板看 / 想提升转化 / 其他
是否允许公开引用原文：默认否
```

如果不确定，就写“默认不公开原文”。

```text
我在验证一个小服务：免费帮前几份招聘 JD / 公开文案做一页“包容性表达审阅报告”，标出可能有性别刻板印象风险的句子，并给中性改写版本。

如果你手头有旧 JD、招聘宣传、课程介绍或营销文案，可以脱敏后发我一段，300-1000 字最好。我不公开原文，只想验证报告有没有用。
```

## 隐私边界

默认规则：

- 不公开原文。
- 不把真实样本提交到 GitHub。
- 不在样例材料中声称“真实客户案例”。
- 不做法律/合规结论。
- 只做写作风险提示和表达改写建议。

如果对方仍担心隐私，可以让对方自己打开 Demo 跑一遍，只把生成的分享包或 Markdown 报告中愿意展示的部分发来。
